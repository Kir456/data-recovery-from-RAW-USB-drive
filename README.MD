# 🔍 TurboRAW Carving Recovery Utility

**TurboRAW Carver** — это высокопроизводительная утилита для восстановления удаленных и поврежденных файлов напрямую с физических носителей (RAW Data Recovery / File Carving) в среде Windows.

Программа работает в обход файловой системы (FAT32, exFAT, NTFS) через Win32 API (`\\.\PhysicalDrive`), используя продвинутые алгоритмы анализа внутренней структуры файлов и защиты от ложных срабатываний (False Positives).

---

## 🚀 Ключевые технические особенности

### 1. Секторное сканирование (512-byte Aligned Search)
В отличие от побайтового поиска, который перегружает процессор, утилита учитывает архитектуру современных ОС: начало любого файла на накопителе всегда выровнено по границе сектора/кластера (кратно 512 байтам). Это дает **ускорение сканирования процессором в ~512 раз**.

### 2. «Бронированный режим» (Structure-Aware Carving)
Для видеоформатов **MP4 / MOV** и **AVI** применяется глубокий синтаксический анализ структуры заголовков:
* Для **MP4/MOV** парсер обходит дерево атомов ISOBMFF (`ftyp`, `moov`, `mdat`), корректно считывая стандартные 32-битные и расширенные 64-битные (`size == 1`) размеры блоков.
* Если точный размер файла вычислен, программа переключается в **«Бронированный режим»**: она скачивает рассчитанный объем видеопотока целиком, **игнорируя любые сторонние сигнатуры внутри**. Это защищает 2–3-часовые видеофильмы от случайного усечения из-за высокой энтропии сжатого видеопотока.

### 3. Поиск истинного конца файла (Trailer Carving)
Для контейнеров и документов (**PDF**, **ZIP/DOCX**, **JPEG**) реализовано отслеживание родных маркеров завершения файла (Трейлеров):
* `%%EOF` — для PDF;
* `PK\x05\x06` (End of Central Directory) — для ZIP;
* `FF D9` — для JPEG.
Выгрузка прекращается сразу при обнаружении трейлера, исключая попадание «мусорных» данных с флешки в конец восстанавливаемого файла.

### 4. Аппаратная совместимость (Advanced Format & 4K Alignment)
* Функция `ReadDiskSafe` автоматически выравнивает любые запросы к физическому диску кратно **4096 байтам** (размер сектора дисков Advanced Format).
* Это исключает системные сбои Windows (`ERROR_SECTOR_NOT_FOUND` / Код 27 / Код 87) при чтении «неровных» хвостов файлов в конце диска.

### 5. Турбо-буферизация (USB 3.0 / NVMe Optimized)
* Чтение с носителя осуществляется блоками по **32 МБ** (`CHUNK_SIZE`).
* При открытии устройства задействуется флаг Win32 API `FILE_FLAG_SEQUENTIAL_SCAN`, который включает агрессивное системное упреждающее чтение (Read-Ahead Caching).

## 📦 Поддерживаемые форматы

| Формат | Сигнатура (Hex) | Алгоритм восстановления | Лимит безопасности |
| :--- | :--- | :--- | :--- |
| **MP4 / MOV** | `66 74 79 70` (`ftyp`) | **ISOBMFF Парсер / Бронированный режим** | 30 ГБ |
| **AVI** | `52 49 46 46` (`RIFF`) | **RIFF Парсер / Бронированный режим** | 30 ГБ |
| **MKV / WebM** | `1A 45 DF A3` | Валидация заголовка (`matroska` / `webm`) | 30 ГБ |
| **JPEG (JFIF)** | `FF D8 FF E0` | Поиск трейлера `FF D9` / Валидация | 15 МБ |
| **JPEG (EXIF)** | `FF D8 FF E1` | Поиск трейлера `FF D9` / Валидация | 25 МБ |
| **PNG** | `89 50 4E 47` | Валидация заголовка | 15 МБ |
| **ZIP / DOCX** | `50 4B 03 04` | Поиск трейлера `EOCD` / Защита вложений | 500 МБ |
| **PDF** | `25 50 44 46` (`%PDF`) | Поиск трейлера `%%EOF` / Защита вложений | 50 МБ |

> **Примечание по защите вложений:** При выгрузке архивов (`.zip`) и документов (`.pdf`) сканер автоматически отключает реакцию на сигнатуры картинок (`.jpg`, `.png`), предотвращая разрыв документа из-за встроенных в него иллюстраций.

## ⚙️ Требования и подготовка к работе

1. **ОС:** Windows 10 / 11 (64-bit).
2. **Права:** Запуск строго от имени **Администратора** (необходимо для доступа к `\\.\PhysicalDriveX`).
3. **Правило дисков:** **НИКОГДА** не запускайте программу и не сохраняйте файлы на тот же диск/флешку, с которого происходит восстановление! Программа должна лежать на быстром SSD (например, `C:\Recovery`), а восстанавливаемый накопитель — подключен как отдельное устройство.

### Как узнать номер диска (PhysicalDrive)
1. Нажмите `Win + X` -> выберите **Управление дисками** (`diskmgmt.msc`).
2. Найдите нужную флешку или диск в нижней части окна. Обратите внимание на подпись: **«Диск 1»**, **«Диск 2»** и т.д.
